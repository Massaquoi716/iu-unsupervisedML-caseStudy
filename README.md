# Mental Health in Technology — Unsupervised ML Case Study

A data science project analyzing mental health survey data from technology-oriented employees.  
The goal is to identify meaningful clusters of participants and provide HR with clear, actionable insights for a mental health support program.

This project was developed as part of the course **Machine Learning — Unsupervised Learning and Feature Engineering** at IU International University of Applied Sciences.

---

## Project Goal

The dataset is high-dimensional, contains missing values, and includes non-standardized text responses.  
The main objectives of this project are:

- Explore and understand the survey data
- Clean and preprocess the data
- Engineer meaningful features
- Reduce dimensionality while preserving key information
- Cluster participants into meaningful groups
- Interpret the clusters and derive actionable insights for HR

## Dataset

- **Expected File Name:** `mental-health-in-tech-2016.csv`
- **Target Location:** `data/raw/`

### How to get the data:
Because data files are omitted from this repository to ensure quick version control performance, you must download the dataset manually using one of the following options:

1. **Direct Download (IU Mirror):** [IU SharePoint Data Hub](https://sharepoint.com)
2. **Original Platform:** [Kaggle — OSMI Mental Health in Tech Survey 2016](https://kaggle.com)

**Instructions:** Create a directory path named `data/raw/` in the project root if it does not already exist, place the downloaded `.csv` file inside it, and verify that it matches the expected file name perfectly.

## How to Run

### 1. Clone the repository
```bash
git clone <the-copied-repository-url>
cd iu-unsupervisedML-caseStudy
```

### 2. Set up the dataset
Follow the steps in the **Dataset** section above to place `mental-health-in-tech-2016.csv` inside `data/raw/`.

### 3. Create a virtual environment and install dependencies
```bash
python -m venv .venv
source .venv/bin/activate          # Linux / macOS
# .venv\Scripts\activate           # Windows

pip install -r requirements.txt
```

### 4. Run the notebooks in order
```bash
jupyter notebook
```

Recommended execution path:
1. `01_eda_and_data_understanding.ipynb`
2. `02_data_preprocessing.ipynb`
3. `03_feature_engineering.ipynb`
4. `04_dimensionality_reduction.ipynb`
5. `05_clustering_and_visualization.ipynb`
6. `reports/04_report.ipynb`

> **Note:** The `data/processed/` folder is generated automatically by the running scripts and is explicitly blocked from tracking.
